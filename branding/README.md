# Jangsang — Branding assets

## Files

| File | Usage |
|---|---|
| `logo.svg` | Logo transparent — sur fond sombre ou coloré |
| `logo-on-dark.svg` | Logo avec fond sombre intégré (carré arrondi) |
| `favicon.svg` | Favicon SVG — identique sur tout fond |

## Concept — Le Caméléon

Un cercle dont l'arc intérieur change d'épaisseur :
- **Arc épais** → puissance, performance, le moteur
- **Arc fin** → légèreté, flexibilité, le skin qui change
- **Ouverture** dans l'arc externe → la transformation en cours
- **Point central** → l'identité stable qui ne change jamais

Même forme, apparences multiples — c'est exactement ce que fait Jangsang.

## Couleurs

| Rôle | Hex |
|---|---|
| Orange (unique) | `#FF6B00` |
| Fond sombre | `#0C0C0C` |
| Fond clair | `#F5F5F5` |

## Règles d'usage

- Logo monochrome orange sur tout fond — ne pas recolorer
- Taille minimum : 24×24px
- Clear space : 20% de la taille du logo sur chaque côté
- Ne pas déformer les proportions
- Le `favicon.svg` est utilisable directement dans `<link rel="icon">`
